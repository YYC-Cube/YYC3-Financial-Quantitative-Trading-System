### 3.4 预见·先知 Prophet — 预测服务 (568行)

| 属性 | 值 |
|------|-----|
| 文件 | `prophet-predictor.ts` |
| 角色 | 系统的"预言家" |
| 格言 | "我观过往之脉络，预见未来之可能" |

**核心能力:**

- Prophet预测器：线性趋势 + 周季节性(7天) + 年季节性(365天) + 不确定性量化
- SimpleARIMA模型：AR(p)系数估计 + d阶差分 + 残差分析 + AIC/BIC
- Prophet+ARIMA集成：加权融合两种预测，动态衰减权重
- 异常检测算法：
  - Z-Score方法：全局均值/标准差偏离检测
  - 移动平均方法：窗口内均值偏离检测
  - 水平偏移检测：前后窗口均值差异检测
- 回测精度评估：MAPE/MAE/RMSE/MASE/R²
- 自动建议生成：基于预测趋势和精度

**测试覆盖:** 23个用例 (Prophet2 + ARIMA3 + 异常检测4 + 集成服务5 + 性能1)
